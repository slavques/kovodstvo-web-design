# Дизайн по «Ководству»: установка и использование

В архиве находится готовая папка `kovodstvo-web-design`. Это самостоятельный навык Codex: интернет при обычном применении не требуется, дополнительных пакетов и API-ключей нет.

## Установить для себя

Скопируйте всю папку `kovodstvo-web-design` в каталог навыков Codex, обычно `~/.codex/skills/`. Должен получиться путь `~/.codex/skills/kovodstvo-web-design/SKILL.md`. Если папка с таким именем уже есть, сначала сравните версии и сохраните собственные изменения.

Откройте новый чат Codex. Если навык ещё не появился в списке, перезапустите приложение. Вызов:

```text
$kovodstvo-web-design
```

Он также может выбираться автоматически по дизайнерской задаче. Это разрешено в `agents/openai.yaml`.

## Добавить в проект для команды

Положите папку в `.agents/skills/kovodstvo-web-design/` внутри общего репозитория и закоммитьте. Коллеги получат её вместе с проектом в поддерживающем такую структуру Codex. Для использования навыка в других проектах им нужна личная установка или отдельная установка из вашего общего репозитория.

Репозиторий нужен для совместного хранения и обновления, а environment — только если вы хотите выполнять саму разработку в Codex Cloud. Архив можно передать коллегам без публикации репозитория. Исходники навыка опубликованы в репозитории slavques/kovodstvo-web-design.

## Примеры запросов

```text
Используй $kovodstvo-web-design. Спроектируй лендинг сервиса [описание].
Аудитория — [кто], главное действие — [что]. Сначала структура на реальном
содержании, затем реализация и проверка узкого и широкого экранов.
```

```text
Используй $kovodstvo-web-design. Проверь существующую страницу [маршрут].
Сохрани айдентику, стек и функции. Исправь группировку, типографику,
навигацию и состояния в рамках этой страницы.
```

```text
Используй $kovodstvo-web-design только для аудита. Ничего не меняй.
Для каждой проблемы укажи элемент, последствие, исправление и проверку.
```

## Как устроено

`SKILL.md` содержит короткое ядро и выбор нужного модуля. В `references/` находятся двенадцать рабочих модулей, каталог всех 160 открытых разделов и машинный индекс покрытия. Каталог не требуется загружать в каждой задаче.

Навык сохраняет выбранный художественный язык. Он не превращает все сайты в монохромные лендинги и не копирует оформление студии автора книги. Подробности разбора, проверки и ограничения — в `ANALYSIS_RU.md`.

## Обновление с версии 1

Личная копия навыка не синхронизируется с GitHub сама. Попросите Codex обновить `kovodstvo-web-design` из этого репозитория, сначала сравнив и сохранив локальные изменения. Или замените папку вручную после сохранения своей версии. Затем начните новый чат. В команде обновите закоммиченную папку навыка обычным изменением общего репозитория.

Версия указана в metadata основного SKILL.md. Версия 2.0.0 сохраняет шесть книжных модулей и добавляет арт-дирекцию, проверку шаблонности, производство графики, motion и выбор инструментов. Подробнее — RESEARCH_RU.md.
