# Ководство: веб-дизайн и арт-дирекция — 2.0.0

Готовый навык Codex для выразительных, работающих сайтов. Фундамент «Ководства» дополнен самостоятельным синтезом современных методов: арт-дирекция из предмета, авторская графика, осмысленная анимация и проверка повторяющихся шаблонов.

Основа изучена по всем 160 разделам открытого оглавления; выполнен обзор 447 вхождений иллюстраций. Современный слой исследован по девяти публичным репозиториям, включая Hallmark, Impeccable, Taste, Anthropic frontend-design и официальные GSAP skills. Версии источников закреплены на 30 октября 2026 года. Это независимый проект, не официальный продукт автора книги или перечисленных команд.

## Установка

Отправьте в Codex:

```text
$skill-installer install https://github.com/slavques/kovodstvo-web-design/tree/main/kovodstvo-web-design
```

После установки откройте новый чат. Если навык не появился, перезапустите Codex. Если версия 1 уже установлена, попросите обновить папку из этого репозитория, сохранив ваши локальные правки: существующая установка сама не обновляется.

Можно скопировать папку `kovodstvo-web-design` в `~/.codex/skills/`. Для команды — в `.agents/skills/kovodstvo-web-design/` общего проекта. Подробности: [INSTALLATION_RU.md](INSTALLATION_RU.md).

## Применение

```text
Используй $kovodstvo-web-design. Сделай сайт [что, для кого, главное действие].
Нужны собственный визуальный характер, законченная графика и осмысленное
движение. Реализуй и проверь реальный результат на широком и узком экране.
```

Для существующего проекта:

```text
Используй $kovodstvo-web-design. Улучши страницу [маршрут]. Сохрани
согласованную айдентику, функции, API и стек; проверь затронутый сценарий.
```

Для аудита добавьте: «Только аудит, ничего не меняй».

## Что внутри

Одно ядро подгружает материалы по задаче. Двенадцать модулей покрывают содержание, композицию, типографику, взаимодействие, визуальный язык, современный веб, арт-дирекцию, повторяемость, производство графики, motion, инструменты и происхождение синтеза. Каталог книги и большой исследовательский индекс не нужны в каждой задаче.

Нет обязательного API-ключа, генератора изображений, Stitch или установки остальных навыков. SVG, CSS и процедурная графика доступны и без сервисов; более сложные инструменты подключаются по задаче и возможностям среды. Скрипт проверки HTML/CSS использует только Python 3 standard library и выдаёт кандидатов на ручную проверку, а не оценку дизайна.

Навык не обещает одинаковую эстетику всем сайтам и не запрещает конкретный цвет или шрифт. Борьба с шаблонами не отменяет выбранную айдентику и привычное управление.
