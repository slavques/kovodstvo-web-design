# Дизайн по «Ководству»

Готовый навык Codex для проектирования и проверки сайтов: композиция, типографика, содержание, навигация, формы и состояния.

Критическая практическая адаптация открытого «Ководства» Артемия Лебедева. Проанализированы все 160 разделов открытого оглавления, выполнен обзор 447 вхождений иллюстраций. Исторические рекомендации отделены от современных требований. Это независимый проект, не официальный продукт автора или его студии.

## Быстрая установка

Отправьте в Codex:

```text
$skill-installer install https://github.com/slavques/kovodstvo-web-design/tree/main/kovodstvo-web-design
```

После установки откройте новый чат. Если навык не появился в списке, перезапустите Codex.

Либо скачайте репозиторий и скопируйте папку `kovodstvo-web-design` в `~/.codex/skills/`. Для общего проекта её можно хранить в `.agents/skills/kovodstvo-web-design/`.

## Использование

```text
Используй $kovodstvo-web-design. Проверь и улучши дизайн этого сайта,
сохранив айдентику, функции и стек. Проверь главный сценарий,
узкий и широкий экраны. Не заявляй о проверках, которые не выполнялись.
```

Для аудита без изменений:

```text
Используй $kovodstvo-web-design только для аудита. Ничего не меняй.
Укажи конкретные проблемы, последствия, исправления и способы проверки.
```

## Устройство

Один короткий навык подгружает нужные модули по задаче:

1. Замысел, содержание и процесс.
2. Композиция и иерархия.
3. Типографика и текст.
4. Навигация, формы и обратная связь.
5. Графика и визуальный язык.
6. Современный веб и проверка результата.

Большой каталог источников не загружается в каждую задачу. Навык не требует API-ключей или дополнительных пакетов и не навязывает всем сайтам одну эстетику. GitHub и Codex Cloud для самого применения навыка не обязательны.
