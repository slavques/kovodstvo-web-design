# Инструменты и сдача

Навык самодостаточен: установка дополнительных навыков, платных сервисов или API-ключей не является условием его работы. Выбирай доступный инструмент после определения результата.

| Возможность среды | Как использовать | Если недоступна |
|---|---|---|
| Разрешённый браузер и скриншоты | Осмотреть реальный рендер, пройти сценарии | Проверить доступные исходники/сборку и честно отметить непроверенный рендер |
| Image generation | Создать нужный растр, осмотреть и встроить | Выполнить SVG/CSS/процедурную графику или использовать разрешённые материалы |
| Дизайн-MCP/редактор макета | Исследовать или изменить предоставленный макет в разрешённом объёме | Работать непосредственно в коде |
| Действующий animation stack | Реализовать выбранную хореографию | CSS/WAAPI или обоснованная разрешённая зависимость |
| Animaxxing / GSAP skills | Подключить конкретный эффект и lifecycle-рецепт | Собственная реализация по официальному API |
| WebGL skills | Подключить подходящую сцену с fallback | Статический или DOM-вариант |
| Stitch | Получить/уточнить макет и семантические роли, когда сервис подключён | Не блокировать разработку из-за отсутствия сервиса |
| Тесты, profiler, accessibility tools | Проверять конкретное поведение или риск | Не приписывать отсутствующие результаты |

Hallmark, Impeccable, Taste и другие источники не требуется устанавливать вместе. Этот навык уже содержит самостоятельный синтез. При явном запросе другого навыка соблюдай его применимые инструкции в пределах запроса, а конфликты решай по требованиям проекта.

## Два независимых просмотра

**Художественный:** сначала посмотри фактический рендер без опоры на машинные флаги. Оцени иерархию, замысел, предметную связь, ритм целого и графику. Не подменяй это списком технических ошибок. На маленькой правке достаточно затронутого элемента.

**Функциональный:** проверь затронутый путь, состояния, клавиатуру, широкий/узкий экран, длинный контент, reduced motion и ошибки загрузки там, где они возможны. Проверяй живое поведение; скрытый overflow-x не доказывает устранение причины переполнения. Независимый просмотр полезен для сложной работы, если он доступен и разрешён; отсутствие такого инструмента не блокирует обычную задачу.

## Вспомогательная статическая проверка

```sh
python3 <папка-навыка>/scripts/design_audit.py <файл-или-папка> --json
```

Скрипт читает HTML/CSS/JS без сети и изменения файлов. Он отмечает кандидатов на ручную проверку: отсутствующий alt, потенциально неподписанное поле, небезопасную ссылку, transition: all и т. п. Он не исполняет JS, не понимает полностью JSX/Vue, CSS cascade и динамические подписи. Нулевая выдача не означает доступность, отсутствие клише или готовность. Для динамического UI используй доступный браузер и подходящие инструменты проекта.

## Конкретный результат

Отдай работающий артефакт в запрошенной среде, краткое объяснение ключевого приёма и фактические проверки. Неподключённую форму, демонстрационные данные, отсутствующий backend и непроверенные устройства обозначь прямо. Не добавляй фальшивую успешную отправку. Исправляй наблюдаемые дефекты, а не бесконечно наращивай число эффектов и правил.
